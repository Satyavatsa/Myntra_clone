# 🛍️ Myntra Website Clone

A frontend website clone inspired by the **Myntra** e-commerce website, created using **HTML5 and CSS3**.

This project was developed as part of my learning journey in **Web Development** to apply HTML and CSS concepts in a practical project.

## 📌 Project Overview

The goal of this project was to recreate the visual structure and user interface of an e-commerce website similar to Myntra.

While building this project, I practiced creating different sections of a modern shopping website, including navigation, categories, product displays and other UI elements.

## 🛠️ Technologies Used

* **HTML5** — Used to create the structure and content of the website.
* **CSS3** — Used for styling, layouts, spacing, colors and overall visual design.

## ✨ Features

* 🏠 Myntra-inspired homepage
* 🧭 Navigation bar
* 🔎 Search section
* 👗 Product/category sections
* 🖼️ Product images and banners
* 🎨 CSS-based styling and layouts
* 📱 Responsive design concepts
* 📂 Organized HTML and CSS files

## 📚 What I Learned

Through this project, I improved my understanding of:

* HTML document structure
* Semantic HTML elements
* CSS selectors and properties
* Flexbox and layout techniques
* Margins, padding and positioning
* Creating navigation bars
* Structuring product sections
* Recreating a real-world website UI

1. Clone this repository:

```bash

```

2. Open the project folder.

3. Open `index.html` in your web browser.

That's it! The website should run locally in your browser.
